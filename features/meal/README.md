# 오늘의 한 끼 (`features/meal`)

**담당:** 팀원 A (홈과 겸임) · **PRD:** Epic B

날씨·시간대·주변 식당을 조합해 "지금 먹을 만한 메뉴"를 추천하고, 끼니를 기록한다.

## 만들 것
- B-1 상황 기반 메뉴 추천 (P0): 끼니 판별, 메뉴 3개 추천, 이유 문구, 다시 추천
- B-2 주변 식당 연결 (P0): 카카오 로컬 API, 반경 1km → 0건이면 3km 제안
- B-3 끼니 기록 (P0): 아침/점심/저녁 하루 1회, 수정·삭제

## 병합 규칙
- `index.ts`는 `Page`, `routes`, `getTodaySummary()`만 내보낸다.
- 경로 `/meal`, 저장소·로컬 키 접두사 `meal_`, 서버 코드는 `api/meal/`
- 개발 중 날씨는 목 데이터를 쓰고, 병합 시 `getWeather(lat, lng)`(팀원 E)로 교체한다.
- 끼니를 기록하면 `meal_logged { mealLogId, slot, date }` 이벤트를 발행한다. (팀원 C의 손님이 병합 시 구독)
- 색·글꼴은 `shared/`의 디자인 토큰만 쓰고, 전역 CSS는 쓰지 않는다.
- 이 폴더 밖의 파일은 수정하지 않는다.
